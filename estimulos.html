Exporta exactamente los mismos pares que ven los participantes humanos (misma semilla, mismo orden) como imágenes PNG, junto con la clave de respuestas y el prompt. También genera datos de entrenamiento con figuras distintas a las del test para entrenar un modelo propio.

Genera pares nuevos con figuras que no aparecen en el test (se excluyen sus formas y sus espejos). Las figuras se reparten entre entrenamiento y validación, así la validación mide si el modelo generaliza a figuras que nunca ha visto. Luego se evalúa con el set del test (apartado 1).
